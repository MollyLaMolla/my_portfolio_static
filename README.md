# 🌐 My Portfolio

An interactive, animation‑rich developer portfolio.  
Explore projects, skills, 3D elements, and a smooth, modern UI built with Next.js.

---

## 🧠 Overview

This portfolio is a fully interactive front‑end and back‑end experience built with **Next.js**, **React**, **Tailwind CSS**, and **TypeScript**.  
It showcases my work, skills, and experience through clean animations, 3D elements, and dynamic UI components.

The site includes a global navigation with bubble‑style scroll effects, tilt‑reactive cards, draggable/spinnable elements, animated transitions, and a built‑in **bug report system** that supports screenshot uploads.

No database is required — everything is handled client‑side or through lightweight server routes.

---

## 🔥 Features

- 🧭 **Animated navigation bar** with bubble scroll effects  
- 🌀 **Interactive 3D elements** using Three.js + React Three Fiber  
- 🎛️ **Tilt effects** on cards and UI components  
- 🌀 **Draggable and spinnable elements** for playful interactivity  
- ✨ **Smooth animations** powered by Motion and Tailwind Animate  
- 🧩 **Projects section** with:
  - Tech icons  
  - Live demo links  
  - Code links  
  - Clean responsive grid  
- 💼 **Work experience section**  
- 🧠 **Skills grid** with icons and categories  
- 🧱 **Approach section** (Phase 1 → Phase 2 → Phase 3)  
- 📝 **About section** with personal introduction  
- 📬 **Contact modal** with:
  - Email  
  - GitHub  
  - LinkedIn  
  - Phone  
- 🐞 **Bug report system**:
  - Name, email, description  
  - Optional screenshot upload  
  - Clean UI for reporting issues  
- 🌙 **Dark mode support** via next-themes  
- 📱 Fully responsive layout  
- ⚡ Built with Turbopack for ultra‑fast dev/build times  

---

## 🎬 Animation & Interaction Highlights

- **Motion** for smooth transitions, fades, slides, and spring animations  
- **React Three Fiber** for 3D models and interactive scenes  
- **Three‑Globe** for animated Earth visualizations  
- **Tilt effects** using custom pointer tracking  
- **Bubble scroll nav** that reacts to scroll position  
- **Hover parallax** on project cards  
- **Lottie animations** for micro‑interactions  
- **Sentry integration** for error tracking
